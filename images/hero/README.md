# Hero-afbeelding

Optioneel: zet hier een foto neer die je op de hero (bovenaan de homepage) wilt
tonen, bijvoorbeeld een foto van een bijlesmoment.

- Formaat: circa 1000x800 pixels (staand of liggend mag beide)
- Bestandsgrootte: onder de 300 KB (comprimeer via bv. squoosh.app)
- Bestandsnaam: `hero.jpg`

Pas daarna in `index.html` de sectie `.hero-visual` aan om de afbeelding te
tonen in plaats van de tekstblok-placeholder.
