# Fotogalerij

Zet hier foto's neer voor de fotogalerij op `ervaringen.html`.

- Formaat: circa 1200x800 pixels (liggend, verhouding 4:3 werkt het mooist)
- Bestandsgrootte: onder de 300 KB per foto (comprimeer via bv. squoosh.app)
- Bestandsnaam: `gallery-01.jpg`, `gallery-02.jpg`, enzovoort

Voeg de foto's daarna toe aan `js/gallery-data.js` — zie de instructies
bovenin dat bestand.
