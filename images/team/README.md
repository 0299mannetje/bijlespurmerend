# Teamfoto's

Zet hier pasfoto's van de docenten neer:

- `loek.jpg`
- `joshua.jpg`
- `benz.jpg`

Formaat: vierkant, minimaal 300x300 pixels. Pas daarna in `over-ons.html` de
`.team-photo`-blokken aan, bijvoorbeeld:

```html
<div class="team-photo">
  <img src="images/team/loek.jpg" alt="Foto van Loek">
</div>
```
