# Reviews

Reviews worden als tekst getoond (niet als screenshot-afbeelding), zie
`js/reviews-data.js`. Deze map is alleen nodig als je later liever
screenshot-afbeeldingen van Google-reviews wilt tonen in plaats van tekst —
dat is een latere, optionele aanpassing en vereist een kleine wijziging in
`ervaringen.html` en `js/reviews-data.js`.
