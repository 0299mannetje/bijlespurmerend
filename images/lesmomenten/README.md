# Foto's van bijlesmomenten

Deze 4 foto's worden op twee plekken op `index.html` gebruikt:

- als rustige zwart-wit achtergrondstrook achter de hero-tekst bovenaan
- in kleur, in een rij van 4, direct onder de kaartjes van "Vijf redenen om met ons te starten"

Bestanden: `foto-01.jpg`, `foto-02.jpg`, `foto-03.jpg`, `foto-04.jpg`

- Formaat: liggend (4:3 of breder werkt het mooist, wordt toch bijgesneden via `object-fit: cover`)
- Bestandsgrootte: onder de 300KB per foto (comprimeer via bv. squoosh.app of `sips -Z 1200 -s formatOptions 75 bestand.jpg --out bestand.jpg`)

Nieuwe foto vervangen? Zelfde bestandsnaam overschrijven, dan hoeft er niets in `index.html` of `css/style.css` aangepast te worden.
